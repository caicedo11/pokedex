# TUTORIAL PASO A PASO DE CÓMO FUE CREADA LA CUENTA EN LA NUBE PUBLICA USADA.

A continuacion detallaremos el  procedimiento paso a paso utilizado para acceder y validar la cuenta de nube pública en **Microsoft Azure** a través de las credenciales institucionales otorgadas por la universidad.

---

# Plataforma y Tipo de Cuenta
 Nube Pública:  Microsoft Azure.
 Tipo de Acceso: Cuenta Institucional / Azure for Students (Credenciales Universitarias).

---

# Paso a Paso para el Acceso a la Cuenta

**Paso 1: Acceso al Portal de Microsoft Azure**
1. Ingresar al navegador web e ir al portal oficial de Azure: `https://portal.azure.com` (o `https://azure.microsoft.com/free/students/` si es la primera activación).
2. Hacer clic en el botón de **Iniciar sesión** (Sign In).

 **Paso 2: Autenticación con Credenciales Universitarias**
1. Ingresar el correo electrónico institucional asignado por la universidad.
2. Serás redirigido al portal de inicio de sesión institucional de la universidad.
3. Ingresar la contraseña institucional correspondiente.

 **Paso 3: Autenticación de Doble Factor (MFA)**
1. Aprobar la notificación de seguridad en la aplicación **Microsoft Authenticator** o ingresar el código enviado por SMS/correo para confirmar la identidad.

**Paso 4: Verificación del Panel Principal (Azure Portal)**
1. Una vez autenticado, el sistema da acceso al **Dashboard (Panel de control) de Microsoft Azure.**
2. Confirmar la suscripción activa (como *Azure for Students* o *Educación*) dirigiéndose a la sección de **Suscripciones** (Subscriptions) en la barra de búsqueda superior.
3. Con este procedimiento la cuenta queda lista para la creación de recursos y para el despliegue del proyecto PokeDex.
